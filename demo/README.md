# 너와나의인계고리 — 시연 데모 (가상 데이터)

**설계를 눈으로 보여주는 발표 보조물.** 제출 산출물(DBML · OAS · 기술서)이 아니다.
버튼 하나가 `OAS 오퍼레이션 → T6 규칙(403/409/422) → DBML 행 변화` 로 이어지는 것을 실증한다.

- **모든 인물 · 입원 건 · 인계 내용은 가상**이다. 환자 마스터를 두지 않는다(병상번호 + 외부 참조 코드만).
- 서버 없음 · 빌드 없음. `demo/index.html` 을 브라우저로 연다 (`file://` 가능. Chrome 기준).
  캐시 때문에 옛 파일이 보이면 강력 새로고침(⌘⇧R). 로컬 서버가 필요하면 `cd demo && python3 -m http.server 8765`.
- 상태는 `localStorage` 에 남는다. 상단 **데모 초기화**(두 번 클릭)로 시드 복원.
- 데모 시계는 **2026-09-16 21:30** 에 고정. 발표일에도 화면이 같다.

## 시드 근무표 (5병동 · A팀 501~503호 · B팀 504~506호)

```
09-15 E  박영숙(A차지·ABSENT·대체 완료)  정하늘(A차지·대체자)      ← 과거 사례 (SUPERSEDED 1건)
09-16 D  박지우(A차지) 윤지아(A액팅) 오다은(B차지) 강나래(B액팅)
09-16 E  한서윤(A차지) 이민혜(A액팅) 서지호(B차지)
09-16 N  정하늘(A차지) 한가람(B차지·ABSENT·대체 전) 최서연(B·역할 미배정)
09-17 D  박지우(A차지)          09-17 N  이민혜(A차지·담당 미지정 → 빈 상태 화면)
```

## 5분 시연 대본

| # | 사용자 | 화면 | 누르는 것 | 보여줄 것 |
|---|---|---|---|---|
| 1 | 김수진 | 대시보드 | — | 미확인 인계 **2건** · 대체 전 결원 **1건**(한가람) · "인계 미작성 N건" 이 **없는 이유** |
| 2 | 김수진 | 배정 보드 (9/16 N) | 최서연 역할 선택 → 저장 | 저장 즉시 반영 · 인계 담당 칩 = 팀 차지 근무에만 |
| 3 | 한서윤 | 내 근무 | 501-3 **작성 계속** → **인계 넘기기** | **422** 필수 2개 비어 있음 → 채우고 다시 → SENT · 받는 사람은 서버가 고른 다음 근무 차지(정하늘) |
| 4 | 정하늘 | 내 근무 | 501-3 **인계 확인** → 요약 없이 **확인 처리** | 화면 진입 = `POST …/receipt` 열람 기록 · **422** 요약 필수 → 요약 입력 → CONFIRMED |
| 5 | 최서연 | 내 근무 | 504-1 **받은 인계 보기** → 확인 처리 | 같은 팀·같은 근무라 **열람은 됨**(읽기 3단 ③) · 확인은 **403** |
| 6 | 김수진 | 대시보드 → 한가람 **재배정** | ④ 먼저 → ② 최서연 → ③ 이관 → ④ | **422**(② 전 ④) · 504-1 인계 **SUPERSEDED + 후속 발행** · covered_at 은 사람의 확인 |
| 7 | 최서연 | 내 근무 | 504-1 **인계 확인** | 대체자가 후속 인계를 받아 확인 → 고리가 닫힘 · "결원 재배정 이력 있음" 표시 |
| 8 | 김수진 | 변경 이력 | — | 4단계 로그 · 사유는 ①에서 한 번만, 나머지는 **복사** |

하단 **API 패널**을 열어 두면 각 버튼의 `METHOD /path → 상태코드` 가 남는다. 4xx 는 빨간색.

## 이 데모가 증명하는 T6 규칙

- 서버 계산 7개: ① `handover_status` ①-b `is_handover_owner` ①-c 인계 ID 두 개 ② `has_reassignment` ③ 대체 완료 가드 ④ `change_reason` 복사 ⑥ 인계의 `to`
- 읽기 3단(`sent_at IS NOT NULL` 기준) · DRAFT 는 작성자만
- 스냅샷 불변 규칙 3 (템플릿을 고쳐도 기존 인계 항목은 그대로 — 화면 5 에서 항목명을 바꾼 뒤 화면 10 을 열어 확인)
- append-only: `handover_assignment` REPLACED · `handover` SUPERSEDED + 후속 발행(한 트랜잭션)
- 예외 1:1 — 403(당사자 아님 · 타 병동) · 404 · 409(중복 · 상태 역행 · CLOSED) · 422(필수 누락 · 가드)
