## 질문이 오면 (제출용 40장 기준)

| 질문 | 답 | 제출용 |
|---|---|---|
| 왜 테이블이 12개나 | 핵심은 6개, 나머지는 병동·팀·사용자·역할·양식·이력. 팀을 빼면 액팅이 인계를 못 읽는다 | 전체 12개 |
| EMR 이랑 이중 입력 아닌가 | 이중 작성은 현장에 이미 있고 당연하게 여긴다. "카덱스 대신 통합적으로 작용한다면 쓰겠다"는 조건부 긍정 | 써 본 사람의 말 |
| DELETE 가 없는 이유 | 지울 사건이 없다. 결원·이관·대체·퇴원 전부 상태로 남긴다. 근무 오등록 취소만 범위 밖 | 지우지 않고 남긴다 |
| 400 은 왜 없나 | 형식 오류는 프레임워크 기본 400. 명세는 뜻이 모자란 요청을 422 하나로 통일해 409(상태)와 갈랐다 | 막을 때 주는 답 · T6-b |
| 왜 열람을 팀·근무로 좁혔나 | 설계 시점엔 관행 정보가 없었고 액팅 참관이 목적이었다. 넓히는 건 판정 한 줄, 보완 | 볼 수 있는 범위 · 써 본 사람의 말 |
