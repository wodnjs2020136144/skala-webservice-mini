### 0-2. F-04 작성 권한 정정 (`docs/02` T4·T6 + 목업 `9`·`10`·`8`)

**현재 목업은 액팅이 작성해서 차지에게 보낸다. 현장 원칙과 반대다.**

- `9_handover_write_nurse` — 작성자를 **팀 차지**로
- `10_handover_receive_nurse` — 수신자를 **다음 근무의 팀 차지**로
- `8_myshift_nurse` (액팅) — **"인계 작성" 버튼 제거**. 액팅은 **열람 + 의견 제시**
- `T4` F-04 권한 문구 · `T6` F-04 행 수정

> **"차지만 작성" 은 현장의 원칙**이고 **"차지 외 `403`" 은 우리의 정책 선택**이다. 이 구분을 문서에 유지한다.
> **확인되지 않은 예외 운용까지 병원이 금지한다고 쓰지 않는다.**

### 0-3. `care_assignment` → `handover_assignment` (**7곳 동시**)

**"FK 이름만 바꾸는 작업" 이 아니다.**

| # | 위치 |
|---|---|
| 1 | `work/DB_sketch.dbml` — 테이블명 + FK 8곳 + note |
| 2 | `ChangeType.CARE_TRANSFERRED` — 이름·note |
| 3 | `docs/02` T4 **F-02 · F-03 의 "담당 환자" 표현** |
| 4 | `docs/02` T5 화면 구성요소 |
| 5 | `docs/02` T6 `assignments[]` 응답 필드 |
| 6 | 목업 `4` · `8` · `9` · `10` 문구 |
| 7 | `work/DB_리뷰요청.md` 구조도 |

**새 정의** (note 와 발표에 그대로)

> **`handover_assignment` = "그 근무에서 이 입원 건의 인계를 작성·수신할 차지를 지정하는 경로"**
> **팀의 환자 범위는 이 테이블이 아니라 `inpatient_stay.team_id` 로 표현한다.**

화면·API 문구도 같이 간다: **"담당 환자" → "우리 팀 환자"**, 내가 차지면 **"인계 담당"** 표시.
`/me/shifts` 는 **팀 환자 목록 + `is_handover_owner`** 로 분리.

> ⚠️ **호실 범위가 고정인 것과 환자 명단이 고정인 것은 다르다.** 환자는 매일 입·퇴원한다.
> *"담당 환자를 미리 안다"* 로 쓰지 않는다.

### 0-4. `team` 도입 + 읽기 3단

```
Table team { id, ward_id, name }        // A팀 / B팀
users.team_id                            // 소속 (근무가 아니라 사람에 붙는다)
inpatient_stay.team_id                   // 이 입원 건의 담당 팀
```

- 팀 이동은 월 1회 있을까 말까 → **이동 이력은 이번 범위 밖**
- **읽기 3단**: ① 병동(`user_type = HEAD_NURSE`) ② `handover_assignment` ③ **같은 팀·같은 근무**
  → ③ 이 없으면 **액팅이 차지가 받은 인계를 못 읽는다.** 권한이 자기 기능을 막는 실수가 두 번 있었다

### 0-5. `role_type` 에 서브차지 (시연 데이터만)

**스키마 변경 없음** — 테이블로 둔 덕분이다. 데이 = 차지1·서브차지1·액팅N / **나이트 = 차지1·액팅1**.

### 0-6. 대시보드 값 → `T6` 매핑

`2_dashboard_manager` 의 각 값에 **조회 API + 데이터 근거**를 붙인다.
**새 기능 번호는 만들지 않는다** — `T5` 가 이미 **진입·집계 화면**으로 정의한다.

> ⚠️ **`인계 미작성 N건` 은 넣지 않는다.** EMR 연동이 없어 *"작성해야 했는데 안 쓴 건"* 을 셀 수 없다.
> `8_myshift_nurse` 의 **"인계 없음"** 표시만 유지한다.

### 0-7. `docs/03` §8 분기 서술 정리

**`사전 배정 + 사후 교환`** 으로. ⚠️ *"분기 A+B"* 는 **철회된 용어**다. 그 말로 고치면 §8 을 또 잘못 고친다.
