## 2. 목 API 계층 — 데모가 설계를 증명하는 지점

`api.js` 는 **T6 의 규칙을 그대로 코드로** 옮긴다. 화면은 이 함수만 호출한다.

- 함수명 = OAS `operationId` (예: `sendHandover`, `confirmReceipt`, `transferHandoverOwner`). 경로·메서드는 로그용 메타로 함께 둔다
- 반환 `{ status, body }` / 실패는 `ApiError(status, message)` — **403 · 404 · 409 · 422 를 T6 예외 열과 1:1**
- 반드시 구현할 서버 계산 7개: ① `handover_status` ①-b `is_handover_owner` ①-c `incoming/outgoing_handover_id` ② `has_reassignment` ③ 대체 완료 가드(4조건) ④ `change_reason` 복사 ⑥ 인계 `to` 자동 선택(D→E→N→다음날 D)
- 반드시 구현할 불변식: 필수 항목 미작성 `422` · `CLOSED` 건 신규 인계 `409` · `SENT` 후 항목 수정 `409` · `CONFIRMED` 재확인 `409` · **읽기 3단**(`sent_at IS NOT NULL` 기준) · SUPERSEDED + 후속 발행 한 트랜잭션 · `CONFIRMED` 이관 `409` · 근무 중복 `409`
- **API 로그 패널**(화면 하단 접이식): 마지막 요청의 `METHOD /path → status` + 응답 요약. 발표 때 "이 버튼이 이 API" 를 보여주는 용도. 상태코드가 4xx 면 빨간색

**단일 출처 원칙 유지**: `api.js` 는 T6 의 **복사본이 아니라 구현**이다. 규칙이 갈리면 T6 가 맞고 `api.js` 를 고친다. 주석에 `// T6 F-04 send · 422` 식으로 출처 행만 적는다.

## 3. 시드 데이터 — 목업 7개의 어긋남을 하나로 맞춘다

**가상 병동 하나**: `5병동` · A팀(501~503호) · B팀(504~506호). 이름은 목업의 가상 이름을 재사용한다.

| 인물 | 팀 | 데모에서 맡는 것 |
|---|---|---|
| 김수진 | 수간호사 | 대시보드 · 근무 등록 · 배정 · 재배정 · 이력 |
| 한서윤 | A 차지 (9/16 E) | 인계 **작성·전달** (501-3 은 DRAFT 로 시드, 필수 2개 비움 → `422` 시연) |
| 정하늘 | A 차지 (9/16 N) | 인계 **수신·요약·확인** |
| 이민혜 | A 액팅 (9/16 E) · 9/17 N 차지(담당 미지정) | **열람만** → 확인 처리 `403` 시연 · 빈 상태 화면 |
| 한가람 | B 차지 (9/17 D) **ABSENT** | 결원 재배정 4단계의 대상 (504-1 · 504-3 담당) |
| 최서연 | B (9/17 D 역할 미배정) | 대체자 후보 |
| 박지우 · 오다은 · 윤지아 | A/B | 근무표를 채우는 인원 |
| 박영숙 | A (9/15 E) | 과거 SUPERSEDED 사례(이력 화면용) |

- 입원 건 8건: A 4건(`STAY-2026-0912-014` 등 목업 코드 재사용) · B 3건 · **CLOSED 1건**(`409` 시연)
- 인계: CONFIRMED 2 · SENT 1 · DRAFT 1 · SUPERSEDED 1 (+후속) — 상태 5종이 전부 화면에 보이게
- 로그: 9/15 박영숙 결원 4행(완결) + 9/17 한가람 `ABSENCE_REGISTERED` 1행(진행 중)
- **시드 검증 함수** `seed.check()`: 한 사람이 같은 날 겹치는 근무 없음 · 모든 인계의 `from→to` 가 시간상 연속 근무 · SUPERSEDED 는 `superseded_by` 있음 · 담당은 팀 차지 근무에만. **콘솔에 위반 0 이어야 통과** (목업의 어긋남을 코드로 잡는다)
- 환자 이름·나이·진단명 없음. 입원 건 코드와 병상만. 자유 텍스트(인계 내용)도 목업의 가상 문장 재사용

## 4. 화면 11개 — 각각 무엇이 "동작"하는가

| 화면 | 동작(목 API 호출) | 시연 포인트 |

| `2` 대시보드 | `getWardDashboard` — 4타일 + 대체 전 결원 표. 값은 **집계 함수**로 계산(하드코딩 아님) | 확인 처리하면 미확인 건수가 줄어든다 |
| `3` 근무 등록 | `listShiftAssignments` · `createShiftAssignments` — 행 추가·저장. 같은 사람·날·조 → `409` | |
| `4` 배정 보드 | `getAssignmentBoard` · `updateShiftAssignment`(역할) · `createHandoverAssignments`(담당 칩 추가). 중복 `409` | 저장 즉시 화면 8 에 반영 |
| `5` 항목 관리 | `listTemplateItems` · `replaceTemplateItems`. 순서 중복 `422`. **이미 만든 인계는 안 바뀜**(스냅샷) | 항목명을 고친 뒤 화면 10 을 열어 안 바뀐 것을 보여준다 |

| `11` 내 이력 | `listMyHandovers` — 방향 탭 · SUPERSEDED 표시 | |

기존 목업의 문구·경고 박스(예: "인계 미작성 N건은 넣지 않는다")는 그대로 옮긴다. **설계 근거 문장은 화면에서 지우지 않는다.**
