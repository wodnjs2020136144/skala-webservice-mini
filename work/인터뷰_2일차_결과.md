- 규칙 1: 환자·사건의 임상 내용은 묻지도 받지도 않았다. 아래에는 **역할·처리 흐름·요청 기능**만 있다

## 0. 확정 2줄 — 설계에 직접 닿는 것

1. **인계 내용은 작성한 본인만 수정할 수 있다. 수간호사도 예외가 없다.** (간호기록도 같은 규칙) `[C]`
   → 우리 `PATCH /handovers/{id}/items` 의 **403(작성자 아님)** 과 같다. **설계 변경 없음.** 현장 규칙과 맞는다는 증거로 쓴다
2. **EMR 에 적은 내용을 카덱스에 또 적는 이중 작성은 지금도 있고, 모두 당연하게 여긴다.** 그리고 **"카덱스 대신 내 시스템이 통합적으로 작용한다면 무조건 쓰겠다"** `[C]`
   → V1(`docs/05` §2-4b) 뒷부분의 답. **이중 입력 우려는 해소.** 대체 성립은 **"통합적으로 작용한다면"이 조건인 긍정** — 조건 없는 긍정으로 올리지 않는다

## 1. 들은 것 (원문에 가깝게)

### 써 본 소감
- UI 는 불편함 없이, **오히려 한눈에 인계를 확인할 수 있어서 좋았다**
- 꼭 있으면 좋겠는 기능: **인계해 준 사람한테 질문할 수 있는 기능** (앱으로 알림이 오고 답변까지)
- 수간호사한테 **결원 배정을 쉽게 할 수 있는 기능**도 너무 도움이 될 것 같다 (옆에서 본 입장 — 수간호사 경험 아님)
- 옆에서 지켜봤을 때 **근무표 만드는 것도 힘들어 보였지만**, 그것보다 **심사과에서 심사하러 올 때 처방 누락건이 종종 있어서** 그걸 잡아내는 시스템이 있으면 좋겠다

### 요청 목록 (참여자 정리 그대로)

**수간호사**
- 심사과 → 처방 누락건 잡아내는 시스템
- 근무표 자동 생성

**간호사**
- 인계해 준 간호사에게 질문 → 앱으로 알림이 오고 답변까지
- 인계 내용 작성 권한을 **작성한 본인만 수정 가능** (실제로 간호기록도 이렇게 진행) → 수간호사도 예외 없음
- EMR → 카덱스에 또 적는 건 중복 작성이지만 **당연히 해야 되는 것으로 인식**
- 약을 받아오면 (60일치 등) **소진 날짜 계산**
- 안약·연고를 받아오면 **유효기간 날짜 계산**
- 처치해야 할 일(주사 등)을 시스템에 등록하면 **알람**
- 환자가 **호출벨을 3회 이상** 누르면 응급 상황 알림 (연동 필요)
- 모든 환자의 **혈압·체온 등을 관제**하는 시스템 (디바이스 필요)
- 주치의에게 보고할 때 **SBAR 를 양식으로 템플릿화**

**원무과**
- 입원 올 때 **ADL 을 주보호자가 작성**할 수 있는 시스템
- AI 로 **신환 정보를 리포트 형식으로 자동 작성** → 간호병동에서 열람
- **퇴원 환자 설문조사** → 불만·칭찬 → 병원 시스템 개선
- 입원 환자 **식이 신청 자동 연동**

> 참고(참여자 제공, 일반 지식): **SBAR(ISBAR) 5단계** — I 신원 / S 상황 / B 배경 / A 사정 / R 요청. 의사 보고 양식이며 인계 양식과는 별개다.
